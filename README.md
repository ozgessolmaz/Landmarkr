Full stack web uygulamamı Java, Spring Boot ve React.js teknolojilerini kullanarak geliştirdim. Backend tarafında kullanıcı işlemleri, veri yönetimi ve REST API servisleri Spring Boot ile inşa edildi. Frontend tarafında ise React.js ile kullanıcı dostu ve dinamik bir arayüz oluşturuldu. Projede JWT tabanlı kimlik doğrulama, veri doğrulama, hata yönetimi ve responsive tasarım gibi modern web uygulama özelliklerine yer verilmiştir.
